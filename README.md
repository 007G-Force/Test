# APEX F1

A cinematic Formula 1 fan-site concept built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy

This project is ready for a standard Vercel deployment. Import the repository, keep the default Next.js settings, and deploy.

## Notes

APEX F1 is an independent fan concept and is not affiliated with Formula 1, the FIA, or any Formula 1 team.
